LCM LAYER 1: PULSE (The Heartbeat)
-----------------------------------

Original Name: MCMC (Markov Chain Monte Carlo)
Final Name: PULSE
Function: Deterministic scheduler for agent timeslices

MATHEMATICAL FOUNDATION:

Metropolis-Hastings Algorithm (1953/1970):
   Developed by: Nicholas Metropolis, Arianna Rosenbluth, Marshall Rosenbluth,
                 Augusta Teller, Edward Teller (1953)
   Extended by: W.K. Hastings (1970)
   
   Original Purpose: Statistical physics simulations
   Context: Manhattan Project legacy → Monte Carlo methods
   
   Algorithm:
   1. Propose new state x' from current state x
   2. Compute acceptance probability:
      α = min(1, P(x')/P(x))
   3. Accept with probability α, else stay at x
   4. Repeat

LUDIGO ADAPTATION:

PULSE transforms MCMC from statistical simulation to deterministic scheduling:

Key Modifications:
1. Seeded PRNG: Every random number reproducible from seed
   Historical: PCG random (O'Neill, 2014) - 128-bit state, O(1) period
   
2. Canonical Ensemble: Fixed temperature τ (no annealing)
   Physical Analogy: Thermodynamic equilibrium at constant T
   
3. Energy Function: E(x) = -Reward(x)
   Minimize energy = Maximize reward
   
4. Best-of-K Selection: Keep best of K proposals
   Enhancement over standard MCMC (standard keeps last accepted state)

Pseudocode:
```
PULSE_Step(agents, K_mcmc, τ, seed):
    RNG.seed(seed)  // Deterministic!
    candidates = []
    
    for k in 1 to K_mcmc:
        x' = Propose(agents)  // LINK → NEXUS → VAULT → HELIX
        ΔE = Energy(x') - Energy(agents)
        
        if ΔE < 0 or RNG.uniform() < exp(-ΔE/τ):
            agents = x'
        
        candidates.append(agents)
    
    return argmin(Energy(c) for c in candidates)
```

Historical Parallel: CPU Schedulers
   • Round-robin (1960s): Fair time-slicing
   • Priority queues (1970s): Importance-based
   • Completely Fair Scheduler (Linux, 2007): Red-black tree
   
   PULSE: Probabilistic exploration-based (novel for OS scheduling)

Theoretical Foundation:
   Detailed Balance: π(x)P(x→x') = π(x')P(x'→x)
   Where π(x) = exp(-E(x)/τ) / Z (Gibbs distribution)
   
   Consequence: Chain converges to stationary distribution
   Ludigo: At equilibrium, agent states sample optimal configurations

Ludigo Q1616 Class (2026) - Direct Descendant:
```python
class Q1616:
    SCALE = 1 << 16  # 65536
    SHIFT = 16
    MIN = -(1 << 31)
    MAX = (1 << 31) - 1
    
    def __init__(self, value):
        if isinstance(value, float):
            q = int(round(value * self.SCALE))
        elif isinstance(value, int):
            q = value
        else:
            q = value.q
        self.q = max(self.MIN, min(self.MAX, q))
    
    def __mul__(self, other):
        if isinstance(other, Q1616):
            prod = self.q * other.q
            if prod >= 0:
                rounded = (prod + (1 << 15)) >> 16
            else:
                rounded = (prod - (1 << 15)) >> 16
            return Q1616(rounded)
        return Q1616(int(round(self.q * other)))
```
